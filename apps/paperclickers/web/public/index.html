Cartões Imprimíveis (TopCodes em Português)

Cada aluno recebe um cartão com seu número. Os cartões contêm as alternativas A, B, C e D em cada lado. Imprima uma única vez e use durante todo o ano letivo!

Como Funciona o PaperClickers na Wizard

1. Imprima os Cartões

Acesse a aba Cartões & PDFs e imprima o pacote em folha A4 (recomendamos 2 por página em papel sulfite 90g ou cartolina). Cada aluno terá seu cartão com número fixo (Aluno 1, Aluno 2, etc.).

2. Projete a Questão

Conecte o notebook ao projetor ou TV da sala. Use o modo 🖥️ Projetor (Atalho F) para exibir a questão com fonte grande e nítida para todos os alunos lerem.

3. Levante o Cartão

Para responder, o aluno levanta o cartão com a letra escolhida (A, B, C ou D) virada para CIMA (teto). A orientação do círculo identifica a opção escolhida.

4. Leitura Instantânea

Com a webcam do notebook ou câmera do celular, aponte para a turma. O sistema detecta todos os cartões simultaneamente em frações de segundo, sem que os colegas vejam a resposta uns dos outros!
